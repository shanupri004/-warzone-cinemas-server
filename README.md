# 🎬 Movie Booking Backend API

A high-performance backend system for a movie ticket booking platform built using **FastAPI**, **PostgreSQL**, and **SQLModel**.  
It provides APIs for managing movies, shows, seat selection, snack orders, and bookings.

---

## 🚀 Features

- 🎥 Movie Management (CRUD)
- 🕒 Show Scheduling (date & time based)
- 💺 Seat Selection System
- 🍿 Snacks & Add-ons Support
- 🧾 Booking & Transaction Handling
- 👤 User-based Booking History
- 🔐 Secure Password Hashing (bcrypt)
- ⚡ FastAPI async performance

---

## 🛠️ Tech Stack

- **Backend Framework**: FastAPI
- **Database**: PostgreSQL (Supabase supported)
- **ORM**: SQLModel / SQLAlchemy
- **Validation**: Pydantic v2
- **Server**: Uvicorn
